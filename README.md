# TG-TOOLKIT

Telegram Management CLI for Termux.

## Goals

- GitHub-backed updates
- Public/authorized Telegram data workflows
- Opt-in group migration and invite management
- CSV utilities and reporting
- Security checks and local configuration protection

## Privacy

TG-TOOLKIT does not attempt to discover private phone numbers, bypass Telegram privacy controls, or force-add users to groups. Sensitive credentials and Telegram sessions must remain local and must never be committed to GitHub.

## Planned command

```text
tg-tool
```
